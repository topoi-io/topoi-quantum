# Topoi Quantum Support

Thank you for using **Topoi Quantum**.

This document explains where to get help, ask questions, report bugs, suggest ideas, and report security issues.

## Questions and help

If you have a question about using Topoi Quantum, please use **GitHub Discussions**:

https://github.com/topoi-io/topoi-quantum/discussions

The **Q&A** category is the best place for questions about:

- installing Topoi Quantum
- using the SDK
- using the `tq` command-line tool
- building quantum circuits
- state-vector simulation
- sampling and measurements
- expectation values and observables
- OpenQASM 3
- circuit drawing
- package usage
- examples and documentation
- quantum-computing concepts related to the toolkit

Please include relevant code, OpenQASM, error messages, package versions, and environment information where appropriate.

## Ideas and feature discussions

If you have an idea for Topoi Quantum or would like to discuss a possible feature, please start a discussion in the **Ideas** category.

GitHub Discussions:

https://github.com/topoi-io/topoi-quantum/discussions

Ideas are encouraged to begin as discussions so that the problem, scope, design, and possible implementation can be explored before development work begins.

Once an idea is sufficiently defined, it may be tracked as a GitHub Issue.

## Bug reports

If you believe you have found a reproducible software bug, please open a GitHub Issue:

https://github.com/topoi-io/topoi-quantum/issues

Before opening an issue, please check whether the problem has already been reported.

A useful bug report should include:

- Topoi Quantum version
- .NET SDK version
- operating system
- affected package or component
- steps to reproduce the problem
- expected behaviour
- actual behaviour
- a minimal code sample or OpenQASM example where possible
- relevant exception messages or console output

General usage questions should normally be posted in GitHub Discussions rather than Issues.

## Documentation

The Topoi Quantum Developer Hub is available at:

https://topoi-io.github.io/quantum/

The repository README also contains installation instructions, quick-start examples, supported features, package information, and current limitations.

If you find an error or omission in the documentation, please open an Issue or contribute a correction through a Pull Request.

## Security vulnerabilities

Please do **not** report security vulnerabilities through public GitHub Issues or Discussions.

Follow the private reporting instructions in:

[`SECURITY.md`](SECURITY.md)

This helps ensure that security-sensitive information is not publicly disclosed before it can be investigated.

You can also use GitHub Discussions to:

- help other community members
